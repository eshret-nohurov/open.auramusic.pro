Решения владельца (21.10.2026), на них держится весь сайт:

- **Сервер:** тот же, что у `web/` (`/opt/bm-web`, nginx + pm2). Сайт живёт в `/opt/bm-open`, порт `127.0.0.1:3310` (3300 занят `bm-web`).
- **Стек:** Go + `html/template`, один бинарник, всё вшито через `embed`. Node/Next.js и фронтенд-фреймворки не использовать. Карточку 1200×630 рисует сам сервер.
- **Бренд:** Belet Music (как в магазинах), хотя домен `auramusic.pro`.
- **«Открыть в приложении»:** Android — кнопка `intent://`, iPhone — только баннер Safari (`apple-itunes-app`). Своей кнопки на iPhone нет: ссылка на тот же домен не открывает приложение. Схемы `beletmusic://` нет и не будет.
- **Дизайн:** как `web/` (тёмный `#121212`, красные кнопки, Jost, новый логотип) + размытая обложка фоном.
- **Язык:** по браузеру (ru → ru, остальное → tm) + переключатель TM/RU в cookie. Превью для мессенджеров (боты) всегда tm.
- **Компьютер:** QR-код + оба магазина.
- **`/`:** 302 на `https://auramusic.pro/tm` или `/ru`.
- **DEV-сборки** iOS и Android включены в файлы связки.
- **Статистика:** счётчики на сервере, без IP, UA, cookies-идентификаторов и кодов ссылок. Сторонних счётчиков нет.
- **Поиск:** `noindex` на всех страницах, но `robots.txt` не запрещает обход (иначе боты превью не прочтут `og:`).
- **DNS и сертификат** делает DevOps, **токен сайта** выдаёт бэкенд (Hakim); 28.10.2026 пришёл токен, один для dev и прод (лежит в `.env.server`, не в git). Локально сайт проверяется на заглушке (`MODE=mock`): с Мака бэкенд ответит `403`.
- **Выкладку** делает владелец сам; агент готовит файлы и пишет шаги, по SSH не ходит.
- Туркменские тексты страницы сочинены не носителем; владелец на 23.10.2026 правок не дал, стоят тексты из задания.

**Why:** задание `~/Desktop/сайт-open-auramusic-промт.md`, раздел 3; владелец ответил на все вопросы 21.10.2026.

**How to apply:** не менять эти решения без владельца. Подробности формата API — [[backend-api]], правила репо — [[git-and-repo]].
